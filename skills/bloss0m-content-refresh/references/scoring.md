# Refresh scoring

Use these dimensions to explain priority. Do not hide judgment inside a single opaque score.

| Dimension | Evidence | Typical action |
| --- | --- | --- |
| Demand | Search impressions, queries, entrances | Rewrite title/description, expand answer, protect route |
| Engagement | Reading depth, return visits, related clicks | Improve opening, structure, visuals, reading path |
| Conversion | Project, contact, RSS, or newsletter events | Align CTA with reader intent |
| Authority | Backlinks, citations, first-hand experiments | Preserve and deepen |
| Freshness risk | Changed APIs, models, prices, security or availability | Re-verify claims and add an explicit review date |
| Isolation | Zero or one relevant internal link | Add pillar, sibling, and case-study paths |
| Overlap | Multiple pages answering the same intent | Consolidate with redirects only after manual review |

Repository-only scoring may flag isolation, missing sources, cluster gaps, and time-sensitive content. It cannot establish demand, authority, or conversion.
