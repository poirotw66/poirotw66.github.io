# Paper-reading article template

Adapt the wording and order to the paper type. Preserve the teaching functions; do not publish placeholder headings mechanically.

```markdown
## 90 秒掌握論文 / The paper in 90 seconds

- **問題 / Problem:** ...
- **核心洞見 / Core insight:** ...
- **最強證據 / Strongest evidence:** ...
- **主要邊界 / Main boundary:** ...

## 理解前需要知道什麼 / What to know first

Define only the prerequisites used below.

## 核心直覺 / Core intuition

Contrast the previous decision rule with the new one before notation.

## 用一個例子走完整個方法 / Walk one example through the method

1. Input: ...
2. Intermediate representation: ...
3. Decision or transformation: ...
4. Output: ...
5. Likely failure point: ...

## 技術機制 / Technical mechanism

Explain the architecture and equations. Define symbols and operational effects.

## 實驗如何讀 / How to read the evidence

For each central result: question → controls → observation → explanation → boundary.

## 證據地圖 / Evidence map

- Paper directly supports: ...
- Author interpretation: ...
- Not established: ...
- Bloss0m engineering judgment: ...

## Artifact 與可重現性 / Artifacts and reproducibility

Record direct endpoint status and an as-of date.

## 工程判斷與不適用條件 / Engineering decision and when not to use it

...

## 讀完後的三個記憶點 / Three things to remember

1. Technical idea: ...
2. Evidence: ...
3. Boundary: ...

## Primary sources
```
